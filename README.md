# HM NET - Sistem Tagihan & Manajemen Redaman Optik FTTH

Aplikasi manajemen tagihan pelanggan (Billing ISP/RT-RW Net), pemantauan redaman optik ONT (Rx Power dBm), pengiriman invoice WhatsApp otomatis, pembukuan kas, dan manajemen hak akses (Multi-Admin / Kasir / Teknisi).

## Fitur Utama
- **Dashboard Analitik & Keuangan**: Pantau pendapatan bulanan, persentase pelanggan lunas, dan grafik kas.
- **Manajemen Pelanggan & Redaman Optik**: Klasifikasi otomatis status redaman sinyal optik ONT (Normal, Warning, Kritis, LOS).
- **Penagihan & Invoice WhatsApp**: Kirim tagihan dan struk pembayaran langsung ke nomor WhatsApp pelanggan.
- **Manajemen Hak Akses (RBAC)**: Kelola akun Admin Induk, Kasir, dan Teknisi beserta izin baca/edit/hapus per fitur.
- **Backup & Restore Database**: Ekspor laporan ke Excel dan cadangkan seluruh data ke file JSON.

## Deployment
Aplikasi ini siap di-deploy secara langsung ke **Vercel** atau **GitHub Pages**.
